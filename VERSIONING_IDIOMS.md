# Versioning policy ownership

The canonical CalVer and artifact qualification scheme for software built by Nix-Alpine now lives in [dash-xd/nix-alpine/VERSIONING_IDIOMS.md](https://github.com/dash-xd/nix-alpine/blob/codex/make-bash-local-orchestration/VERSIONING_IDIOMS.md).

Smoke's `versioning` package on this working branch is experimental reusable Go validation and publication-interface code, **not** the owner of Nix-Alpine release policy or qualification authority. It has not been integrated into Nix-Alpine's Makefile. No production publication or promotion adapter is qualified.

Smoke's own composition and workspace identities remain observational as specified in `SMOKE_IDIOMS.md`.
